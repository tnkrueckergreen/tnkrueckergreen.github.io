# tommy's capstone project

my capstone website! i wanted something cleaner and more personal than a google site, so i built it from scratch.

nothing fancy, but *simple*, *minimal*, and *clean*. and rounded corners for the win!

## about

a single-page site with four sections — home, discover, design, and deliver — navigated with hash routing. embeds google docs, sheets, and drive videos for all my capstone artifacts. sticky nav, responsive on mobile. and i spent way too long picking the right shade of beige.

## tech

- plain `html`/`css`/`js`
- fonts shamelessly stolen from a website i liked (inspect element → network tab → download the `woff2` files for anyone interested). then i proceeded to rebrand them as tommySans and tommySerif
- css flexbox layout
- hash-based routing with `popstate`
